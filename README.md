# Fractal

Desenha algo pequeno e vê-o repetir-se dentro de si mesmo, como um fractal — e a crescer para sempre.

Abre `index.html` no browser (não precisa de instalação).

- **Ramos** — uma cópia mais pequena nasce na ponta de cada traço (árvores, corais…).
- **Túnel** — o desenho repete-se dentro de si, a rodar e a encolher.
- **Floco** — cópias à volta do desenho.
- **Crescer** (ou tecla espaço) — zoom infinito: o desenho cresce e as cópias continuam a aparecer sem fim.

O ponto verde marca a âncora (início do primeiro traço): é daí que as cópias se ligam às pontas.
